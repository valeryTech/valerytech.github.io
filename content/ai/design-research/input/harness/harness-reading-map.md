## Suggested reading order


1. **Externalization in LLM Agents** for the broad perspective.
2. **Harness-Building for Coding Agents** for a functional decomposition.
3. **How Codex Is Built** for a concrete engineering account.
4. **Object-Oriented Harness** for specialization and task-specific selection.
5. **Type-Oriented and Functional Harnesses** for the proposed alternative.
