# Production Readiness Research Inputs


The files in this directory are historical source material used to develop the production-readiness work. They are not normative definitions of the current model or framework.

Their terminology predates the explicit separation between:

- the [Production Readiness Model]({{< ref "ai-engineering/other/production-ready/production-readiness-model" >}}), which owns stable concepts, properties, relationships, and boundaries; and
- the [Production Readiness Framework]({{< ref "ai-engineering/other/production-ready/production-readiness-framework" >}}), which owns operationalization, derivation, dimensions, criteria, workflows, roles, governance, artifacts, adoption, and measurement.

References to a "model" in these input files may therefore describe concerns that the current documents assign to the framework. Preserve the input text as source evidence; use the model and framework documents as the authoritative terminology.
